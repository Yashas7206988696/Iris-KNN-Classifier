# Iris-KNN-Classifier
## Overview
This mini-project shows how to build a **K-Nearest-Neighbors (KNN)** classifier on the classic Iris flower data set using scikit-learn.  
In fewer than 30 lines of code you will:

1. Load the Iris data.
2. Split it into training / test sets.
3. Train a KNN model (default k = 3).
4. Evaluate accuracy and print a confusion-matrix & classification report.
5. Plot a quick sepal-length vs sepal-width scatter for intuition.

Great as a starter template for anyone learning KNN or scikit-learn.

## Quick Start
git clone https://github.com/your-user/Iris-KNN-Classifier.git
cd Iris-KNN-Classifier
pip install scikit-learn pandas matplotlib
python knn_iris.py # runs training + metrics + plot
